# Colaborar

Gracias por ayudar a mejorar Magic Mouse for Windows. Describe el problema antes de proponer una solución y mantén los cambios pequeños y verificables.

Para UI, adjunta capturas claras en modo claro y oscuro. Para HID, indica modelo, versión de Windows y controlador. Elimina rutas privadas e identificadores antes de compartir reportes. No copies código ni controladores de proyectos con licencias incompatibles.

Ejecuta las pruebas del núcleo y, para cambios de interfaz, el diagnóstico integrado de WinUI. Las contribuciones mantienen la licencia MIT del código original; las dependencias conservan sus licencias.
